# grilling density reduction

## proposal

two stages, write round as already there

then try prompt

```
paragraphs in the round are too dense,
ive trouble following up and keeping up, 
could you use more paragraphs to help me read the round
```

## Results (2026-11-25)

Both stages ran; the prompt was fired twice against live grill-me rounds, both confirming the diagnosis. Settled decisions:

| # | Topic | Decision |
|---|-------|----------|
| Q1 | Scope | All round prose is affected (round intro, recap branch summaries, question Abstracts) — not a single stage. |
| Q2 | Remedy | Split only, no trim — more, shorter paragraphs; content preserved (issue 28 Q10 depth rule intact). |
| Q3 | Frame rule | The Abstract's "3–5 sentences per paragraph, 1–2 is too thin" rule is replaced by **content slots** (decided context, concrete failure, decision point) with no sentence floor. |
| Q4 | Pacing | Hard cap: **≤2 sentences per paragraph**, everywhere in a round (intro, recaps, Abstracts), testable like the rest of the template. |
| Q5 | Venue | Record here; edit `skills/grill-me/SKILL.md` in the repo (single draft home per issue 28 Q17/Q18). |

Live test resumes with the next grill-me session.

## Revisions (2026-11-25, grilling round on hard caps)

The ≤2-sentence hard cap (Q4 above) survived one testing cycle and then failed feel-review: too rigid, decided wraps belong to the model. Literature check (NN/g, plain-language.gov, WebAIM) supports idea-based paragraphing over counts: one idea per paragraph, topic sentence first, short sentences (comprehension ~100% at ~8 words/sentence, dropping past ~25). Settled:

| # | Topic | Decision |
|---|-------|----------|
| R1 | Primary rule | Idea-based: one idea per paragraph, topic sentence first; uneven paragraph lengths are fine. The 2-sentence mark is a **warning**, not a limit. |
| R2 | Sentences | Favor short, informative sentences; no numeric target (informational basis: comprehension curve); no cap. |
| R3 | Verification | Model self-checks the finished round against the Pacing criteria before sending. |
| R4 | Options | Options/Recommendations lists unchanged — one idea each by construction. |

These supersede Q4 for `skills/grill-me/SKILL.md`; a new `Pacing` section holds the rules. Recorded alongside issue 35 (word budget, still open).

## Additions (2026-11-25, second live-cycle review)

Two recurring deviations from live rounds (issue 9 planning session) got their failing tests and fixes:

| # | Topic | Observation | Decision |
|---|-------|----------|
| A1 | Branch digest | A branch settling 4–5 decisions renders them in one 5-sentence paragraph — the exact wall Pacing targets; scanning literature (NN/g: 79% always scan, keyword lead-ins anchor) says list, don't paragraph. | ≥3 settled decisions per branch → one bullet per decision, tag-first (proto-legend shape); 1–2 decisions stay prose with a topic sentence. |
| A2 | Trailing recap | Two consecutive rounds appended an unstructured `## Round n — recap` tail naming retained questions, instead of using the Remaining-frontier line. | Retained questions are named on the Remaining-frontier line only; no trailing recap section (one line added to the template). |

Self-check misses inside round prose (intro split across ideas) remain agent-level slips; no skill edit can restiffen them without re-introducing counts.
