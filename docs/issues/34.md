```
paragraphs in the round are too dense,

```

## Results (2026-11-25)

Both stages ran; the prompt was fired twice against live grill-me rounds, both confirming the diagnosis. Settled decisions:

| # | Topic | Decision |
|---|-------|----------|
| Q1 | Scope | All round prose is affected (round intro, recap branch summaries, question Abstracts) — not a single stage. |
| Q2 | Remedy | Split only, no trim — more, shorter paragraphs; content preserved (issue 28 Q10 depth rule intact). |
| Q3 | Frame rule | The Abstract's "3–5 sentences per paragraph, 1–2 is too thin" rule is replaced by **content slots** (decided context, concrete failure, decision point) with no sentence floor. |
| Q4 | Pacing | Hard cap: **≤2 sentences per paragraph**, everywhere in a round (intro, recaps, Abstracts), testable like the rest of the template. |
| Q5 | Venue | Record here; edit `skills/grill-me/SKILL.md` in the repo (single draft home per issue 28 Q17/Q18). |

Live test resumes with the next grill-me session.
