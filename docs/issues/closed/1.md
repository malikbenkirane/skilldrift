# Create core-commands skill for jj repo workflow

## Problem

Working in jj-based repositories requires clear guidelines for prohibited commands and a reliable pattern for passing multi-line content to shell commands.

### Issues to address

1. Git commands are sometimes used in jj repos, causing confusion
2. Certain jj commands produce incoherent output or have destructive behavior
3. Heredocs and echo for multi-line content have escaping issues and produce unreliable output

### Solution

Create a `core-commands` skill that:
- Documents prohibited git and jj commands with alternatives
- Establishes the temp file pattern (`mktemp` + Write tool) for multi-line content
- Provides common mistakes guidance for any jj-based repo
